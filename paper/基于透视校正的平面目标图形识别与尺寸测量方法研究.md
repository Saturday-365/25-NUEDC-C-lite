# 基于透视校正的平面目标图形识别与尺寸测量方法研究

## 摘要

针对摄像头拍摄平面目标时存在视角倾斜和透视畸变，导致内部图形识别稳定性下降、尺寸测量误差增大的问题，本文设计了一种基于透视校正的平面目标图形识别与尺寸测量方法。该方法首先对图像进行灰度化、二值化和形态学处理，通过轮廓筛选与多边形逼近提取目标板外框四个角点；随后利用四点单应性变换将倾斜目标板校正为近似正视图；最后在校正图像中提取内部图形轮廓，并依据顶点数、轮廓面积比和圆形度等特征完成图形分类与尺寸换算。实验部分将比较透视校正前后在不同角度和距离条件下的识别准确率及尺寸测量误差，以验证透视校正对平面目标视觉测量的改善效果。

关键词：透视校正；单应性矩阵；轮廓检测；图形识别；尺寸测量；OpenCV

## 1 引言

### 1.1 研究背景

数字图像处理广泛应用于工业检测、目标定位、机器人视觉和自动测量等场景。在平面目标测量任务中，摄像头通常无法始终保持与目标平面完全垂直，拍摄图像会受到透视投影影响。原本规则的矩形、圆形或三角形在图像中可能发生形变，从而影响后续识别和尺寸计算。

### 1.2 研究意义

对于具有已知外框尺寸的平面目标，可以通过检测外框角点建立图像平面到目标平面的映射关系，并利用透视变换获得正视校正图像。该过程能够减小视角变化带来的形状畸变，使内部图形识别和尺寸测量具有更稳定的输入基础。

### 1.3 本文主要工作

1. 设计基于 OpenCV 的 PC 端图像处理实验流程，支持 USB 摄像头采集和静态图片处理。
2. 基于目标板外框轮廓提取四个角点，并完成透视校正。
3. 在校正图像中完成三角形、正方形和圆形的识别与尺寸测量。
4. 通过校正前后对比实验分析透视校正对识别准确率和测量误差的影响。

## 2 相关理论基础

### 2.1 图像预处理

本文使用灰度化降低图像通道复杂度，使用 Otsu 二值化突出黑色目标区域，并通过形态学闭运算连接边缘断裂区域、抑制局部噪声。

### 2.2 边缘与轮廓提取

目标板和内部图形具有明显的黑白边界，因此可以通过二值图像进行轮廓提取。轮廓面积、中心位置、凸性和多边形近似顶点数可用于筛选目标板外框和内部图形。

### 2.3 多边形逼近与角点排序

对外框轮廓使用多边形逼近后，若得到四个凸四边形顶点，则将其作为透视变换的源点。四点按照左上、右上、右下、左下排序，保证与目标正视矩形的点序对应。

### 2.4 透视变换原理

平面目标在摄像机成像中可由单应性矩阵描述。设原图点为 $(x, y)$，校正图像点为 $(X, Y)$，二者满足：

```text
[x', y', w']^T = H [x, y, 1]^T
X = x' / w'
Y = y' / w'
```

其中 $H$ 为 3x3 透视变换矩阵。通过目标板外框的四组对应点可以求得该矩阵，并将目标板图像变换到正视平面。

### 2.5 基于比例关系的尺寸测量

在校正图像中，目标板宽高对应已知真实尺寸。由像素尺寸和真实尺寸可得到比例系数，并将内部图形的像素边长或直径换算为实际尺寸。

## 3 方法设计

### 3.1 总体流程

```text
图像采集或图片输入
  ↓
灰度化、二值化、形态学处理
  ↓
目标板外框轮廓检测
  ↓
四角点提取与排序
  ↓
透视校正
  ↓
内部图形轮廓提取
  ↓
图形分类
  ↓
尺寸与面积计算
```

### 3.2 目标板外框检测

首先对输入图像进行黑色区域二值化，然后提取外部轮廓。根据面积比例筛除小噪声区域，再使用多边形逼近获得候选四边形。最终选择面积最大的四边形作为目标板外框。

### 3.3 透视校正

将检测到的外框四角点作为源点，将目标板理想正视矩形四点作为目标点，使用 OpenCV 的 `getPerspectiveTransform` 计算透视变换矩阵，并通过 `warpPerspective` 得到校正图像。

### 3.4 内部图形识别

在校正图像中去除边缘区域后，再次提取黑色轮廓。对每个候选内部轮廓计算多边形近似顶点数、最小外接矩形、最小外接圆和圆形度：

- 顶点数为 3 时判定为三角形；
- 顶点数为 4 且外接矩形宽高比接近 1 时判定为正方形；
- 圆形度较高时判定为圆形。

### 3.5 尺寸与面积计算

根据目标板真实宽高和校正图像像素宽高计算像素到毫米的比例。三角形使用平均边长估计实际边长；正方形使用最小外接矩形宽高均值估计边长；圆形使用最小外接圆估计直径。面积计算公式如下：

```text
三角形面积 = a^2 * sqrt(3) / 4
正方形面积 = a^2
圆形面积 = pi * (d / 2)^2
```

## 4 实验设计

### 4.1 实验环境

- 操作系统：Windows
- 编程语言：Python
- 图像处理库：OpenCV
- 输入设备：普通 USB 摄像头或静态测试图片
- 目标板：A4 纸打印黑色外框和内部几何图形

### 4.2 数据采集方案

建议采集以下图片：

| 类型 | 条件 |
|---|---|
| 角度变化 | 0 度、15 度、30 度、45 度 |
| 距离变化 | 100 cm、150 cm、200 cm |
| 光照变化 | 正常光、弱光、侧光 |
| 图形变化 | 三角形、正方形、圆形、组合图形 |

### 4.3 对比实验

实验比较两种处理方式：

1. 不进行透视校正，直接在原图中提取内部图形和测量尺寸。
2. 进行透视校正后，在校正图像中提取内部图形和测量尺寸。

### 4.4 评价指标

| 指标 | 含义 |
|---|---|
| 外框检测成功率 | 是否正确检测目标板四角点 |
| 图形识别准确率 | 内部图形类别是否判断正确 |
| 尺寸绝对误差 | 测量尺寸与真实尺寸的差值 |
| 尺寸相对误差 | 绝对误差占真实尺寸的比例 |
| 处理稳定性 | 不同角度和距离下结果波动情况 |

## 5 结果分析

### 5.1 透视校正效果分析

对比原图和校正图，分析目标板外框是否由倾斜四边形恢复为矩形，内部图形是否更接近真实形状。

### 5.2 图形识别结果分析

统计不同拍摄条件下图形识别准确率，分析角度增大、距离变化和光照变化对识别结果的影响。

### 5.3 尺寸测量误差分析

比较校正前后的尺寸测量误差。重点分析倾斜角度较大时透视校正对测量精度的改善。

### 5.4 误差来源

主要误差可能来自：

1. USB 摄像头镜头畸变；
2. 外框角点提取误差；
3. 二值化受光照影响；
4. 透视变换插值导致边缘变化；
5. 轮廓近似参数对结果的影响。

## 6 结论与展望

本文设计了一种基于透视校正的平面目标图形识别与尺寸测量方法。该方法通过目标板外框角点建立透视变换关系，将倾斜拍摄的平面目标校正为正视图，再基于轮廓特征完成内部图形识别和尺寸换算。后续实验将进一步验证透视校正对识别准确率和尺寸测量误差的改善效果。

后续可从以下方向改进：

1. 引入摄像头标定，进一步降低镜头畸变误差；
2. 使用 HSV 或自适应阈值增强光照鲁棒性；
3. 优化外框角点检测算法；
4. 对重叠图形加入更稳定的分割方法。
